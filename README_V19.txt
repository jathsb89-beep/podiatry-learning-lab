PODIATRY LEARNING LAB — VERSION 19 CLEANUP

This is a cleaned build of the user's uploaded Version 18 website.

CHANGES
- Removed old Version 14, 15 and 16 standalone sections from the visible layout.
- Retained the subject-centred study hub and its existing lecture notes, flashcards, anatomy tools, questions, and local progress logic.
- Removed obsolete version banner from the timed exam.
- Added horizontal overflow protection for iPad screens.

IMPORTANT
- This ZIP does NOT contain original university lecture PDFs. None were included in the uploaded Version 18 ZIP.
- Existing study summaries remain. Original PDFs can be integrated into the lecture library once supplied.
- The legacy HTML/JS remains embedded for compatibility; old standalone sections are hidden, not physically deleted. This is a safe UI consolidation, not a full codebase refactor.

INSTALL
1. Unzip this archive.
2. Upload index.html to the repository root, replacing the old lowercase index.html.
3. Keep your existing image, CSV, JSON and other assets in GitHub.
4. Commit and reload the website. Safari may need a refresh to clear the old page.
5. Do not clear Safari site data: it contains local study progress.
